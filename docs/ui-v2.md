# UI v2 — 训练指挥台（Training command center）

这一版**不改任何内容、计划定义、进度语义、URL、双语行为、搜索覆盖或判分逻辑**。
改的是「一个人打开这个站，两秒之内能不能回答三个问题」：

```
我在准备什么？      → 侧栏常驻的「我的计划」+ 进度
我走到哪了？        → 计划页的路线图 / 页内那条位置带
下一步做哪一件事？  → 全站每一屏只有一个视觉主导的动作
```

上一版（意图优先导航 + 引导计划）功能是对的，毛病在**同等重量的选择太多**：
顶栏有「计划徽标 + 四个模式 + 继续」，侧栏又有「计划面板 + 接着学 + 课程树 +
下一节卡片」。两套导航体系同屏竞争，于是「下一步」被稀释成六七个都挺重要的东西。

---

## 1. 新的导航层级：**只有一套**

```
┌────────────────────────┬──────────────────────────────────────────┐
│ DrillLab               │ 面包屑（我在哪）           搜索 语言 主题 │
├────────────────────────┼──────────────────────────────────────────┤
│ ● 今天                 │                                          │
│ ● 我的计划             │              内容                        │
│   ▸ 进度 4 / 130       │                                          │
│   ▸ 〔继 续〕          │   ← 全站唯一的视觉主导动作在这里或页内     │
│                        │                                          │
│ 资料库                 │                                          │
│   学课程               │                                          │
│   背知识点             │                                          │
│   做练习               │                                          │
│                        │                                          │
│ 检验                   │                                          │
│   考场                 │                                          │
│   模拟考               │                                          │
│                        │                                          │
│ 使用说明 / 速查        │                                          │
│ ─────────────          │                                          │
│ 〔当前页的上下文〕      │                                          │
└────────────────────────┴──────────────────────────────────────────┘
```

**顶栏不再有第二套导航。** 顶栏只剩「我在哪」（面包屑）和四个工具
（搜索 / 语言 / 主题）。原来顶栏那四个模式标签整块搬进侧栏的
「资料库 / 检验」两组 —— 位置固定，每一页都在同一个 y 坐标上，
`aria-current="page"` 标当前项。

**侧栏上半（导航位）在所有页面完全一致**，只有分隔线以下那一段随页面变化
（课程页给课程路线图、八股页给方向筛选、练习页给题型筛选……）。
这条是硬规矩：导航位一动，人就得重新找。

**「继续」全站只有一处** —— 侧栏计划块里那一颗。顶栏那颗删掉了。
（跟着计划时它指计划的下一格；没跟计划时指上次停下的地方。算法仍然是
`lib/plan-progress.ts` 里那一条，一处也没动。）

## 2. 新访客的路径：三选一，不是六选一

```
              什么都想学        →  完整学习路线（推荐，唯一的实心按钮）
你要为什么做准备？ →  准备一场考试  →  展开 4 个紧凑子项：React / Federation
                                       / Spring Boot / Cab Booking
              准备面试          →  前端面试复习
```

第一屏**只放这三个决定**，不放六张密卡。选中「准备一场考试」才展开那四个
子项（渐进披露），四个子项是紧凑的一行一个，不是四张大卡。
「看全部计划 →」是一个安静的文字链，通往 `/plans`。

四个模式的入口和课程目录**从第一屏移除**，降到下面一节
「浏览全部材料（Explore the library）」，标题层级明显更低。

## 3. 回访者的路径：首页就是学习仪表盘

跟着计划的时候，首屏**只有这些**：

```
React Assessment                                    ← 计划名
Stage 1 of 7 · Prerequisites: Foundations           ← 当前档
4 / 130 ▓▓░░░░░░░░░░░░  还剩约 14 小时               ← 进度 + 剩余估时

┌─────────────────────────────────────────────────┐
│ LEARN   Stage 1 · item 4 of 9        ~12 min     │  ← 下一件事那张大卡
│ The directory layout of both exam projects       │
│ 为什么是它：先认识两个项目的目录，后面每一节都在其中一个里 │
│ 〔继 续 →〕                                       │  ← 唯一的实心按钮
└─────────────────────────────────────────────────┘

当前档预览：✓ 01  ✓ 02  ✓ 03  ● 04 现在  ○ 05  ○ 06     ← 完成 / 当前 / 后两三个
```

再往下才是「浏览全部材料」，一个安静的分区，永远不和「继续」争视觉重量。

## 4. 计划页：一条旅程，不是一张数据库导出

```
头部   计划名 · 一句话结果 · 进度 · 当前档 · 剩余估时 · 〔继续〕
       「换一条 / 先不跟」是两个安静的文字按钮

路线图 一条竖线，粗体编号节点
  ①  ✓ 已完成的档          折叠（编号 / 名字 / 条数 / 估时 / 状态）
  ②  ● 当前档              展开
       ├ 当前那一格：突出显示
       ├ 后面两三格：一行一个
       └ 「看全部 9 条 →」   ← 剩下的在这后面
  ③  ○ 还没到的档          折叠
```

**不再一屏铺几十上百行。** 完整学习路线那条计划有 350 条 —— 老版本把 20 个档
全展开，等于把数据库倒在屏幕上。现在默认只展开当前档，且当前档里也只露
「当前 + 后三格」，其余在「看全部」后面。折叠/展开是 `<details>`，
200ms 的高度过渡。

## 5. 课程页：一栏内容，一条位置带

老版本是「三个应用并排」：侧栏有计划大卡 + 计划外的链接 + 全局进度 + 课程树 +
下一节卡片；正文顶上又有一条计划带；右边还有目录。

现在：

- **侧栏**：一块紧凑的「继续」，下面是课程路线图。**计划大卡删掉**。
- **正文顶部**：一条**紧凑**的位置带 —— `React Assessment · Stage 1 of 7 ·
  item 4 of 9 · 回到计划`。一行，不是一张卡。
- **右侧目录**：只在 ≥1280px 出现。窄一些的宽度上收成正文里一个
  「这一页有什么」的折叠控件。
- 正文层级加强：课名用几何无衬线、字号提到 40px；总览 / 学完你会 /
  讲解 / 练习 / 迁移 之间用 32px 的段间距和一条细线分开，不再用浅色底块堆叠。

## 6. 四个模式页共用一套模板

`/drill`（背知识点）、`/practice`（做练习）、`/code`（Coding）、`/arena`（考场）
统一成：

```
眉题 / 面包屑
大标题（38–46px）
一句话说明它是干什么的
计划上下文（如果在计划里）    ← 一行，安静
进度摘要                     ← 全站同一个组件
筛选 / 动作行                 ← 同一个高度、同一个圆角
内容
```

容器宽度、标题对齐轴、垂直节奏、卡片内边距、筛选控件尺寸、按钮高度、圆角、
空状态写法**全部共用**，靠 `styles/layout.css` 里那一套原语，不各写一遍。

## 7. 视觉方向

深色、高对比、几何无衬线。**没有衬线标题、没有薄荷绿洗色、没有玻璃拟态、
没有渐变卡片、没有彩虹档位色。**

```
--app        #090C0B   页面底
--panel      #101512   侧栏 / 面板
--raised     #171D19   抬起的卡
--hover      #202821   悬停
--ink        #F4F7F5   正文
--ink-2      #A0AAA4   次要
--ink-3      #758079   元信息
--rule       #28322C   边界
--accent     #B8F23D   强调（柠檬绿）
--accent-h   #D0FF6A   悬停
--accent-ink #10140D   强调底上的字
--ok #63D69A  --info #62B7FF  --warn #F5C451  --danger #FF746C
```

**强调色只用在四个地方**：当前位置、进度、主 CTA、极小的高亮。
不整卡铺柠檬绿。

间距是 8 的倍数：`8 / 16 / 32 / 48–64`。卡片内边距 20–24，圆角 12–14。
字号：hero 52–60 / h1 38–46（移动 32–36）/ 正文 15–17 / 元信息 12–13。
等宽字体只留给代码、序号和紧凑元信息。

主题切换保留（顶栏工具之一）。深色是这一版的设计方向，浅色是它的高对比对偶
（同一套语义变量换一组值），不是薄荷纸感那一版。

## 8. 移动端

顶栏压成：品牌 · 〔继续〕· 搜索 · 菜单。全部导航进一个抽屉。
第一屏必须看到页面标题和主动作 —— 不许先滚过一屏导航才到正文。
计划的档变成单列手风琴。抽屉的 Escape 关闭和焦点归位照旧。
所有可点区域 ≥44px。

## 9. 动效

只用来解释状态变化，且尊重 `prefers-reduced-motion`：

```
手风琴开合   180–220ms
悬停 / 聚焦  120–160ms
进度变化     250–350ms
页面入场     ≤220ms 的透明度 + 位移
```

没有循环装饰动画。新访客首屏允许**一处**克制的环境光晕。

## 10. 性能与无障碍的底线

首屏 JS 不许实质回归（当前实测：课程页 144 / 首页 174 / `/plans` 136 /
计划详情 170 kB；上限分别是 150 / 180 / 145 / 180）。

保持：WCAG AA 对比度、可见的键盘焦点、语义地标、`aria-current`、
计划进度的无障碍描述、双语、减少动效、**不出现两个同等的主动作**。
