# IA 审计 · 第三轮

用户反馈原话：**「打开看了一下觉得有点乱，无从下手，不知道该怎么开始。」**

前两轮改过首页 hero 和顶栏（记录在 `components/home.tsx` 与
`components/app-shell.tsx` 的头部注释里），用户仍然觉得乱 —— 所以这一轮不碰那两处，
往下一层找。

审计方式：清空 `localStorage`，以全新用户身份实走
「首页 → 开始第一课 → 练习 → 考场」以及「首页 → 四档任一入口」，
用 DOM 断言数每一页的**可见**术语数、可见去处数、可见文字量。
（不用抓 HTML 数 —— 第一次那样做时把 RSC payload 里的 `$L1b` 误当成了「L1」。）

## 二、逐条核实外部审计的线索

### 线索 1 —— 三套并行分类系统 · **确认，且比描述的更严重**

`components/practice-page.tsx` 的实际顺序：

```
第 100 行  <Ladder current="exercises" />     ← 口径 A：四档（说得出/认得出/写得对/空手做）
第 103 行  <div className="callout">          ← 口径 B：L1–L4 阶梯，整段解释
第 159 行  <div className="filters">          ← 按考试筛
第 182 行  <div className="filters">          ← 口径 B 又一次：L1/L2/L3/L4 当筛选值
第 198 行  <div className="filters">          ← 口径 C：六种练习类型
第 290 行  <div className="rail-head">        ← 口径 C 又一次：右栏「练习类型」计数
```

**口径 B 和 C 各出现两次**（一次当解释文案、一次当筛选器），所以一个新用户在这一页要
消化的是：4 档 × 4 级 × 6 类，外加「按考试筛」四门课。**分类学本身变成了要先学的内容。**

术语实测 15 个：说得出 / 认得出 / 写得对 / 空手做 / L1 / L2 / L3 / L4 / Debug Lab /
认出来 / 排顺序 / 填空 / 写整块 / 从零重写 / 难度。

**另外发现一处口径重叠**：口径 B 的「L1 认出来」和口径 C 的「认出来」是**同一个词**，
但在 B 里指「一个难度档」，在 C 里指「一种练习类型」。同名不同义，这是最坏的一种重叠。

### 线索 2 —— 首页四档卡片缺「什么时候来」· **确认**

首页可见 8 个分类术语、9 个去处、651 字。四档卡片给出 4 个带数字的并列入口
（99 / 123 / 16 / 6），**没有任何一条说明「什么时候该来这一档」**。
主 CTA 刚立起来的「先上课」路径感，立刻被四个同等重量的入口稀释。

### 线索 3 —— 第一课是驾驶舱 · **确认，但已部分缓解**

实测第一课（`/exams/foundations/node-and-npm`）：

- 侧栏 **18 个可见链接 / 9 个可见课时**（审计说约 24 —— 那是模块折叠之前的数；
  本轮之前刚做过「只展开当前模块」，所以实际比审计描述好一些，但仍然是 18 个）
- 右栏 **3 块**：本节目录 / 当前位置 / 真实来源
- 面包屑、「学完这节你会 / 这在考试里考什么」双卡片、真实文件表 **全部在首屏之上**
- 第一屏 900px 内 **13 个可点元素**

对第一课的新手，这是驾驶舱不是教室 —— 确认。

### 线索 4 —— `/practice` 信息权重弄反 · **确认**

页面第一句是「全站 123 个练习都在这里，可以按考试、难度、类型筛」——
先说的是「怎么筛」，而不是「这一页是干什么的、我该不该现在来」。
而练习的主要消费路径是课文页尾的「练习 · 动手做」那一段，hub 是次要入口。

### 线索 5 —— 课文页尾链路完整 · **确认，不动**

`NextLesson` 的「标记学完 → 接着往下看」是全站唯一一条闭合的推进链路，本轮不碰。

### 额外发现（审计没提）· E 项「同一个地方两个名字」**确认有真问题**

扫了全站所有指向暗路由的链接文字：

| 路由 | 被叫过的名字 |
| --- | --- |
| `/drill` | 八股题库 · **说得出**（首页）· 回题库 |
| `/code` | Coding 题 · **写得对**（首页）· Coding |
| `/practice` | 练习 · **认得出**（首页） |
| `/arena` | 考场 · **空手做**（首页）· 回考场列表 |
| `/mock` | 模拟考 · **模拟考的自评视图**（首页折叠区） |
| `/path` | 看完整路径 · 或者看整条路线图 · **全部课文** · 回到路线图 |

**首页把四档的「目标动词」当成了链接文字**（`.tier-goal` 在 `.tier-name` 上方且字号更小，
但视觉上它是那一行的第一个词）。于是新用户在首页学到的名字是「说得出」，
点进去页面标题却是「八股题库」，顶栏那一项又叫「练习」。**同一个地方三个名字。**

`/path` 最乱：四种叫法，其中「全部课文」和「路线图」听起来像两个不同的页面。

## 三、收敛方案

### 唯一对用户露出的模型

```
学（课程） → 练（跟着课文走的练习） → 验（考场）
```

四档**保留为这条路径的刻度**，只在**一个地方**完整解释（`components/ladder.tsx`），
别的页面只引用不重讲。

术语统一表 —— 一个地方一个名字：

| 路由 | 唯一名字（zh / en） | 四档刻度（副标，不当链接文字） |
| --- | --- | --- |
| `/path` | 课程 / Learning path | — |
| `/practice` | 练习 / Practice | 认得出 |
| `/drill` | 八股题库 / Interview drills | 说得出 |
| `/code` | Coding 题 / Coding problems | 写得对 |
| `/arena` | 考场 / Arena | 空手做 |
| `/mock` | 模拟考 / Mock exams | （在考场里） |
| `/reference` | 速查表 / Reference | — |

### 逐页动作

| 页面 | 删 | 降级 | 改 |
| --- | --- | --- | --- |
| `/practice` | **整个 L1–L4 说明 callout**（口径 B 的解释文案） | 三排筛选器合成一组，不配解释 | 页首第一句改成「这一页是干什么的」；默认筛选跟随当前进度；右栏无进度时不显示 0/123 |
| `/` 首页 | — | 四档数字视觉降级 | 每档加一行「什么时候来」，状态从进度派生；链接文字改成正式名字，四档刻度退为副标 |
| 第一课 | — | 右栏「当前位置 / 真实来源」折叠进 `<details>` | 只有「本节目录」默认展开 |
| `ladder.tsx` | — | — | 成为四档唯一完整解释处 |

「L1–L4」这套编号**不从数据模型里删**（`Exercise.level` 还在用，`/practice` 的难度筛选
也还需要它），只是**不再作为一套需要用户学习的体系去解释**。筛选器上仍然显示 L1–L4
作为难度值 —— 那是过滤器的刻度，不是第二套世界观。

### 为什么第一课右栏选「一律折叠」而不是「按进度区分」

右栏三块是**服务端渲染**的，而「这个人有没有进度」只有客户端知道（`localStorage`）。
按进度区分要么把折叠状态交给客户端小岛（首屏会闪一次「展开 → 收起」），
要么把内容搬进客户端（违反「课文不进客户端 chunk」）。

所以选：**第一部分的课一律只默认展开「本节目录」**，另两块折叠进可展开区。
老学员点一下就能展开，而「第一课信息过载」这件事对老学员其实也成立 ——
没必要为了区分身份引入首屏闪动。

## 四、实施记录（Phase 3）

### A · 分类收敛

| 动作 | 文件 |
| --- | --- |
| **删掉整块 L1–L4 阶梯解释 callout** | `components/practice-page.tsx` |
| 难度筛选加一行含义，挂到四档语言上 | 同上（`.filter-hint`） |
| 「练习类型」筛选保留为 chips，不配解释 | 同上（本来就没有额外解释，确认无需改） |
| 四档的完整解释只留在一处 | `components/ladder.tsx`（原本就是唯一完整解释处） |

**删掉的原文**（`/practice`，标题 + 两段）：

> **按难度往上走，别停在 L2**
> **L1 认出来**（N 个）帮你把概念对上号；**L2 填空**（N 个）让你注意到关键位置；
> **L3 写整块**（N 个）才开始真正生成代码；**Debug Lab**（N 个）练的是考场上最费时间的那件事；
> **L4 从零重写**（N 个）是唯一能证明你真会了的一关。
>
> 填空做全对不代表能通过考试。**能从空文件写出来才算。**

英文版同时删掉（`Climb the levels — do not stop at L2` 那一块）。

**L1–L4 没从数据模型里删** —— `Exercise.level` 还在用，难度筛选也还需要它。
它现在只是筛选器上的刻度，加了一行「L1 → L4 和上面四档同一个意思：给你的东西越来越少」。

### B · 首页

- 四档区块改成数据驱动（`TIERS` 数组 + `tierState()`），数字仍从 `NAV` / `DRILLS` /
  `CODING` / `ARENA` 派生，一个都没写死。
- **每档加一行「什么时候来」**，三态从进度派生：`later` / `now` / `open`。
  门槛：练习 = 开始上课就来；八股 = 走完一门课；Coding = 做过 ≥ 5 个练习；
  考场 = 前两个条件都满足。**四个链接始终能点，没有锁死逻辑、没有任务面板。**
- 数字降级：`.tier-n` 从 12px/650 改成 11.5px/600 + `opacity: .75`。
- **链接文字改成正式名字**（八股题库 / 练习 / Coding 题 / 考场），
  四档刻度（说得出…）从左侧徽章退成名字下面的小字副标。
- 布局从两列（徽章 | 内容）改成单列纵向，`@media (max-width: 560px)` 里
  针对旧两列布局的那段随之删除（变成死代码）。

### C · 第一课

- 右栏「当前位置」和「真实来源」合并折叠进一个 `<details>`，
  默认只展开「本节目录」。右栏块数 3 → 2。
- 选「一律折叠」而非「按进度区分」，理由见上一节末尾。
- 侧栏模块折叠（本轮之前刚做）已把当前课的可见链接从 18 降到只展开当前部分。

### D · `/practice`

- 页首第一句从「全站 123 个练习都在这里，可以按考试、难度、类型筛」
  改成「**练习跟着课文走 —— 每节课尾都有本课的练习。** 这一页是全部练习的总库，
  想集中刷题的时候来。」
- 新增 `components/practice-focus.tsx`（客户端小岛，**不接收任何内容**）：
  首次进入没带 `?exam=` 且有进度时，把 URL 换成你正在学的那门课。
  换完显示一行「已筛到你正在学的《X》。想看全部就点上面的「全部」」——
  **自动筛掉东西必须说出来**，静默隐藏等于「我的练习不见了」。
  用 `router.replace` 而不是 `push`，否则「后退」会退回同一页形成死循环。
- 右栏无进度时不显示「0 / 123」，改成「怎么用这一页」+ 一句引导。

### E · 名字统一

| 路由 | 改前（多个名字） | 改后 |
| --- | --- | --- |
| `/path` | 看完整路径 / 或者看整条路线图 / **全部课文** / 回到路线图 | 看全部课程 / 先看全部课程挑一段 / **课程** / 回到课程 |
| `/mock` | 模拟考 / **模拟考的自评视图** | 模拟考 |
| `/drill` `/code` `/practice` `/arena` | 首页用「说得出 / 认得出 / 写得对 / 空手做」当链接文字 | 首页改用正式名字，四档刻度退为副标 |

## 五、验证结果（Phase 4）

清空 `localStorage` 走全程：

| 检查 | 结果 |
| --- | --- |
| 首页主 CTA | 新用户「开始第一课」；有进度「回到这一节」 |
| 首页四档链接文字 | 八股题库 / 练习 / Coding 题 / 考场 ✓ |
| 首页四档刻度 | 说得出 / 认得出 / 写得对 / 空手做（副标）✓ |
| 新用户四档状态 | 全部 `later`，四条门槛提示各不相同 ✓ |
| 有进度（走完地基 9 节、0 个练习） | 八股 `now`、练习 `now`、**Coding `later`、考场 `later`** —— 派生逻辑真的在区分 ✓ |
| `/practice` L1–L4 说明块 | 已消失（`txt.includes("按难度往上走")` = false）✓ |
| `/practice` 页首第一句 | 已改成定位说明 ✓ |
| `/practice` 右栏 | 无进度时是「怎么用这一页」，`0 / 123` 不出现 ✓ |
| `/practice` 自动聚焦 | `/practice` → `/practice?exam=react`，123 → 54，并显示提示行 ✓ |
| 第一课右栏 | 2 块，「当前位置 · 真实来源」默认闭合 ✓ |
| 移动端 390px | 抽屉里主导航四项齐全，无横向溢出 ✓ |
| 英文版 | 四档名字 / 刻度 / 四条门槛提示 / 折叠区链接全部有英文 ✓ |

**术语计数没有下降**（`/practice` 仍能数出 15 个词），这是**预期的**：
L1–L4 和六种练习类型仍然作为筛选器的刻度存在。
真正变化的是**解释的套数从 3 套降到 1 套** ——
四档在 `ladder.tsx` 讲一次，L1–L4 压成筛选器旁边的一行标注，
练习类型只是 chips。新用户不再需要先学三套体系才知道该点哪。
